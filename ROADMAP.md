# Salesforce learning and build roadmap

Time budget: 6–8 hours/week. This workstream is independent of AEP and AJO but shares integration contracts in the future capstone.

| Week | Focus | Hands-on output | Exit criteria |
|---|---|---|---|
| 1 | CRM platform and object model | Lead/Contact/Account/Opportunity/Case map | Explain standard objects and relationships |
| 2 | Data quality and consent | Field ownership and deduplication rules | Identify source of truth and duplicate strategy |
| 3 | Automation | Flow design for lead routing and task creation | Entry, fault and recursion behaviour documented |
| 4 | REST integration | API payload and auth sequence design | OAuth, idempotency, retries and errors covered |
| 5 | Data Cloud / Data 360 | Unified profile and identity design | Separate CRM records from unified profile concept |
| 6 | Agentforce | Agent topic/action/guardrail blueprint | Least privilege, grounding and human handoff defined |
| 7 | Closed-loop integration | AJO outcome to Salesforce task simulation | Duplicate events do not create duplicate tasks |
| 8 | Portfolio demo | CRM + AI workflow walkthrough | Demo, tests, security notes and limitations complete |

Weekly cadence: 2 hours concepts, 2–3 hours build, 2–3 hours test/document. Real org and Agentforce practice require appropriate licenses and permissions.
